# Security Policy

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, use GitHub's **Private Vulnerability Reporting** on the affected repository:

- [`obscura-app` Security Advisories](https://github.com/obscura-messaging/obscura-app/security/advisories/new)
- [`obscura-native` Security Advisories](https://github.com/obscura-messaging/obscura-native/security/advisories/new)
- [`obscura-server` Security Advisories](https://github.com/obscura-messaging/obscura-server/security/advisories/new)
- [`obscura-proto` Security Advisories](https://github.com/obscura-messaging/obscura-proto/security/advisories/new)

Include a clear description of the issue, the affected component(s), and steps or proof-of-concept to reproduce.
