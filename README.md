# .github

Organization-wide GitHub configuration and default community health files for [`obscura-messaging`](https://github.com/obscura-messaging):

- [`profile/README.md`](profile/README.md): Public organization profile rendered on the `obscura-messaging` overview page.
- [`SECURITY.md`](SECURITY.md): Default security and private vulnerability reporting policy inherited by all repositories.
- [`pull_request_template.md`](pull_request_template.md): Default pull request template across repositories.
